BRIGHTPATH TUITION CLASSES - HTML WEBSITE

Files:
1. registration.html - Student registration page
2. login.html - Student login page
3. courses.html - Courses page
4. feedback.html - Feedback page
5. pricing.html - Price details page

All five pages are connected through the navigation bar and footer.
Social-media icons use Font Awesome via CDN.

How to run:
Open registration.html (or any HTML file) in a web browser.

Note:
The forms are front-end only and do not store data because no backend/database is included.
